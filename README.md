# 新概念音游 · 来吧，走↑起↓（gqk-piano-tiles）

**🎮 在线试玩：<https://123xiaojun.github.io/gqk-piano-tiles/>**

一个**单文件、零依赖、离线可玩**的极简黑白节奏小游戏，用原生 JavaScript 写成。灵感来自“别踩白块 / 钢琴块”，但把规则收紧成一条：**从下往上，只能按最底下那一块**。

可以随意更改图片和音效，只需把对应文件放进 `sucai/` 目录、保持文件名不变即可。

如有什么问题，也请及时跟我说明，我会及时修改。

> 整个游戏就是一个 `index.html`，双击即玩，不需要服务器、npm、构建工具或任何第三方库。

![游戏画面](screenshot.png)

## 玩法

- 屏幕是 **12 行 × 4 列** 的棋盘，每行随机出现 **1 个**白色方块。
- **按下第一块才开始计时**，限时 **20 秒**。
- 必须 **由下往上依次按**，且 **只能按最底下那一行**的那一块。
- 按下的方块会移到最底行停一下并显示“已按下”的图案，然后滑出屏幕。
- 踩到以下任一情况立即结束：
  - **越级按** —— 按了最底行以外的任何格子；
  - **按到非钢琴块区域** —— 同一行里点空位（每行只有 1 块是真的）。
- 最高分存在 `localStorage`，关掉浏览器也在。

## v2.0.0 更新

- **修复方块图案完全不显示**：CSS 里 `background-image` 的路径漏了 `sucai/` 前缀，浏览器一直在请求根目录下不存在的 `gqk.png` / `gqk1.png`。
- **修复按下方块“一闪就没”**：方块 class 拼接时少了一个空格，被拼成了 `tileimg`，什么都匹配不上；同时按下后的重绘会把方块状态清掉。现在按下的方块会留在最底行，看得见反馈。
- **按下状态图案三级兜底**：优先 `sucai/gqk2.png` → 没有则退到 `sucai/gqk1.png` → 再没有则退成纯色块（把 `gqk2.png` 放进 `sucai/` 即自动生效，不用改代码）。
- **新增 `sucai/to-png.html`**：任意图片一键转 PNG 的纯前端小工具。
- **音效文件名统一为小写**（`yinxiao.mp3` / `yinxiao1.mp3`），与页面引用一致，在区分大小写的服务器（如 GitHub Pages）上不会再 404。
- **资源统一收进 `sucai/` 目录**，与文档描述一致，根目录不再堆散图。

## 特性

| 特性 | 说明 |
| --- | --- |
| 单文件分发 | 逻辑 / 样式 / 结构全在 `index.html`，无外部依赖、无 CDN |
| 纯随机但不无解 | 每行只有 1 块；同一列最多连出 3 次（`COL_RUN_MAX`），避免手感诡异 |
| 按需生成 | 开局先算 11 行，之后按需补充，永远不空转、不越界 |
| 低延迟输入 | 优先 `pointerdown`，`click` 兜底并用时间戳去重；35ms 防连点 |
| 几何命中判定 | 按触点坐标找出格子，而非依赖事件目标，1~2px 缝隙不会误判 |
| 按下有反馈 | 按下的方块滑到最底行、换成“已按下”图案，不再瞬间消失 |
| 音频双通道 | 同源走 **Web Audio**（可精确掐断），跨域自动降级到 `<audio>` 媒体通道 |
| 音频地址探测 | 依次尝试 相对路径 → 同协议绝对地址 → 强制 https → 强制 http，第一个能拿到音频的胜出 |
| 图片三级兜底 | `gqk2.png` → `gqk1.png` → 纯色块，缺图也能玩 |
| 图片格式无忧 | 附赠 `sucai/to-png.html`，任何格式的图拖进去就转成 PNG |
| 移动端适配 | 紧凑间距、`viewport-fit=cover`、禁用长按菜单与双击缩放 |
| 自检可见 | 页面把音频状态、构建号、脚本错误直接打印在状态条下方，方便排查 |

## 快速开始

**方式一：直接打开**

```
双击 index.html
```

**方式二：本地起个静态服务**（推荐，音效更稳）

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

├── .nojekyll           # 让 GitHub Pages 跳过 Jekyll 预渲染

    ├── gqk1.png        # 方块图案（已按下 · 兜底）
    ├── gqk2.png        # 方块图案（已按下 · 可选，放了就优先用它）

## 图片转 PNG 工具（sucai/to-png.html）

双击打开即可，**纯前端、不上传、不联网、零依赖**：

- 拖拽图片到虚线框，或「选择图片」/「选择文件夹」批量导入，也支持 `Ctrl+V` 粘贴截图
- 支持 jpg / jpeg / webp / gif / bmp / avif / svg / ico 等一切浏览器能解码的格式
- 自动按 EXIF 转正手机照片方向；本来就是 PNG 的原样直通，不重压、不拆帧
- 逐个预览 + 单个下载 / 全部下载 PNG，重名自动加 `-1`、`-2`

## 音效配置

游戏按顺序探测音效地址，第一个真正能取到音频的胜出。如果音效放在 CDN / 对象存储，用 URL 参数覆盖即可：

```
index.html?sndbase=https://your.host/audio
```

> 注意：**https 页面只能加载 https 音效**，否则会被浏览器的混合内容规则拦掉。内网穿透（frp 等）场景下，建议直接用穿透的 http 地址访问，或给面板也配上 https。

`audio-test.html` 是一个独立的**音效地址探测小工具**，会逐个测试同一文件的不同协议 / 端口写法并给出可用结论，方便定位混合内容问题。

## 可调参数

都集中在 `index.html` 顶部的 `/* ======= 参数 ======= */` 区块：

| 参数 | 默认 | 含义 |
| --- | --- | --- |
| `ROWS` | 12 | 棋盘行数 |
| `COLS` | 4 | 棋盘列数 |
| `DURATION` | 20 | 限时（秒） |
| `PRESS_MS` | 35 | 防连点间隔（毫秒） |
| `START_ROWS` | 11 | 开局一次性渲染的行数 |
| `COL_RUN_MAX` | 3 | 同一列最多连续出现次数 |
| `HEADROOM` | 40 | 前方预留行数，滚出屏幕的方块会被回收 |
| `BUILD` | 19 | 构建号，显示在页面上用于确认加载到了最新版 |

## 部署

纯静态，丢哪都能跑：**GitHub Pages、Vercel、Netlify、Cloudflare Pages、Nginx、宝塔面板**，或者任意静态托管。仓库根目录就是站点根目录。

GitHub Pages 的开启方式：仓库 **Settings → Pages → Source: Deploy from a branch → Branch: `main` + `/ (root)` → Save**，随后访问 `https://<用户名>.github.io/<仓库名>/`。

> ⚠️ 上传时要把 `index.html` 和 `sucai/` 文件夹**一起**放到仓库根目录；只传 index.html 会导致图片和音效全部 404。
